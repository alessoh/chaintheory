# Appendix G. The Chain Theory Building Set

*An interactive companion. Status as of November 22, 2026; program documents at commit a28db89.*

The Chain Theory Building Set is an interactive page made for this book. It presents the program's webs as ball-and-stick models built from the compendium's data file, with a ball for every site and a rod for every link. There are twenty-one models: the nineteen webs of the compendium's catalog and the two nucleon stars of Appendix F. A reader can turn each model, pull on a site, and select a link to learn whether it is readable or dark, which the page calls clear or hidden. Below the models the page states the valence law and the read cap, offers three short trials on a maximally entangled pair, follows the count of 172 records to the candidate value of the inverse fine-structure constant, 137.035 999 189 566, and lists four measured quantities that the program does not reach. The page is written in plain language. The shapes of its models carry no content, and every identification of a web with a particle is a conjecture.
